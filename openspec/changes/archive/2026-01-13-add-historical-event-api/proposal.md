# 提案：增加历史事件列表接口

## 背景
当前系统仅提供了基于 Stream (Watch) 的实时事件接口，用户无法查看系统过去发生的事件记录。为了提升系统的可观测性和审计能力，需要增加历史事件列表接口，支持对事件进行筛选（任务类型、状态、时间范围）和分页查询。

## 目标
1. 提供全局历史事件列表接口。
2. 提供针对特定资源的历史事件列表接口。
3. 支持按任务类型（备份、恢复等）进行筛选。
4. 支持按任务状态（成功、失败、进行中）进行筛选。
5. 支持按时间范围筛选。
6. 事件信息包含：时间、任务类型、任务名称、集群/命名空间、状态、耗时、触发人等。

## 范围
- **V1 阶段**: 重点支持 `AppBackup` 和 `AppRestore` 资源的事件展示。
