# 变更：新增 AppBackup 相关集群列表 API

## 为什么 (Why)
在展示“应用备份列表”的页面中，用户需要能够筛选“来源集群”。这个筛选列表不应该列出系统中注册的所有集群，而是应该只列出那些**确实作为来源集群参与了应用备份**的集群。这样可以避免筛选出空结果，提升用户体验。

## 变更内容 (What Changes)
- **新增 API 路由**:
  - `GET /disaster/v1/app-backups/clusters` -> 返回所有在 AppBackup 资源中出现过的 unique 集群名称列表。

- **实现详情**:
  - 该 API 将调用 AppBackupLister 获取所有 `AppBackup` CR。
  - 遍历所有 `AppBackup`，提取 `spec.cluster` 字段。
  - 进行去重处理（Set 逻辑）。
  - 返回去重后的集群名称列表。返回结构建议复用 `DisasterClusterNameDTO` 或简单的名称字符串数组。鉴于一致性，我们可能只需返回 `[{"name": "cluster-a"}, ...]` 结构。

## 影响 (Impact)
- **新增功能**: 为前端应用备份列表页面的筛选器提供数据支持。
- **性能**: 需要遍历所有 AppBackup 对象。考虑到 AppBackup 数量可能较多（成百上千），但依然是在内存中进行去重，且仅操作元数据，性能消耗在可控范围内。如果数量级达到数万，可能需要考虑加索引或缓存，但目前阶段直接遍历即可。
